## T1 是什么线路，和 Premium / Eyeball 有什么区别

很多人被 DMIT 的命名搞糊涂。这里直接列清楚：

DMIT 每个机房都有三条产品线，定位完全不同：

- **Premium**：三网优化，CN2 GIA 回程，晚高峰最稳，最贵
- **Eyeball**：CMIN2 / 9929 优化线路，性价比中间档，大陆访问比 T1 强不少
- **Tier 1（T1）**：纯国际 Tier 1 运营商线路，不含大陆优化，价格最低

T1 接入了 Arelion（AS1299）等多个国际 Tier 1 运营商，同时接入了 GSL（Global Switch London）网络，亚太和美洲内部延迟优化做得不错。不过从国内访问来看，高峰期延迟不稳定，丢包情况也比 Premium 明显，这点没必要回避。

说实话，T1 的用户画像就是：自己跑技术，需要干净的国际 IP，或者有专线/中转方案配套使用。

## T1 的三个值得说的地方

**超额不断网，限速继续跑。**

T1 全系的设计是：流量用完后不关机，而是降速。LAX T1 限速 100Mbps，HKG 和 TYO 的 WEE 套餐限速 50Mbps。个人用站、小项目跑起来，基本不用担心月底流量不够用就突然下线的情况。这一点在同价位商家里不算标配，算是加分项。

**AMD EPYC 处理器，硬件规格实在。**

AN4 平台用 EPYC 9004 系列，AN5 平台更新到 EPYC 9005。两代都是企业级 CPU，KVM 虚拟化，NVMe SSD 存储。从跑分来看，AN5 单核跑分比 AN4 高出一大截。T1 这个价位能拿到这个规格，硬件层面没什么可挑的。

**IP 换掉很麻烦，要提前想好。**

T1 系列目前换 IP 需要付费，且要人工审核。这和 LAX Pro/EB 系列的自助更换不一样。如果你对 IP 干净度有要求、或者业务场景需要经常换 IP，T1 不太适合，换到 LAX Pro 或 EB 会省很多事。

## FAQ

**Q：DMIT T1 适合搭建梯子吗？**

国内方向没有优化，不推荐。T1 高峰期从国内访问延迟明显，用来翻墙体验会比较差，建议考虑 LAX.EB 或 LAX.Pro 系列。

**Q：T1 流量用完会不会关机？**

不会。LAX T1 超额后限速 100Mbps 继续跑，HKG 和 TYO 的 WEE 套餐限速 50Mbps，其他套餐限速也类似。站点不会因流量触顶而宕机。

**Q：T1 的 IP 质量怎么样？**

T1 的 IP 不保证在所有国家或地区都能正常使用，DMIT 官网有明确提示。流媒体解锁方面，Netflix 只能看 Originals，Disney+ 基本被封。YouTube、Amazon Prime Video 等可正常访问。IP 干净度取决于你拿到的具体 IP。

**Q：T1 能不能随时换 IP？**

目前 T1 系列换 IP 需要付费，且需要人工审核，不支持自助更换。和 LAX Pro/EB 系列的体验不一样，要换 IP 的用户需要联系客服处理。

**Q：DMIT 支持哪些付款方式？**

PayPal、支付宝、信用卡都支持，对国内用户来说操作没有障碍。
